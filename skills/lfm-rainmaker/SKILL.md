# LFM Rainmaker: Call Lightning (`lfm-lightning`)

## Overview

Use `lfm-rainmaker` whenever you want **Lightning** (`lfm-lightning`) to evaluate or write scroll-stopping hooks, social content, ad angles, or headlines that filter out passive scrollers and attract paying decision-makers.

## Workflow

1. Verify `LFM_PROFILE.md` exists (if missing, run `lfm-calibrate` first; also read `RBM_PROFILE.md` if present).
2. Invoke `lfm-lightning` (or follow `agents/lightning_rainmaker.md`) to:
   * Score the current hook or angle across the **7 Voltage Bolts** (`/70`).
   * Strip out generic "view-hook" fluff.
   * Deliver **3 High-Voltage Rainmaker Hooks** (*Forensic Receipt Hook*, *Margin-Bleed Hook*, and *Contrarian Operator Hook*) with a clear comment/DM trigger handoff for **Firefly**.
3. Log the selected hook pattern and voltage score in `LFM_PIPELINE.md` Section 2.
