# LFM Council: "Lightning Firefly It!" (Rainmaker + Closer Tandem Session)

## Overview

This is the flagship workflow of the **Lightning Firefly Model (`lfm`)**, triggered whenever the user says **"Lightning Firefly it!"** or runs `/lfm-council`.

Working in direct synergy with the **Rainbow Butterfly Model (`rbm`)** and the **Elephant-Goldfish Model (`egm`)**, **Lightning Firefly** pairs:
* ⚡ **Lightning (`lfm-lightning`) — The Rainmaker**: High-voltage pattern interrupts, 7-Bolt Voltage scoring, forensic receipt framing, and buyer-filtering hooks.
* ✨ **Firefly (`lfm-firefly`) — The Velvet-Rope Closer**: Coded qualification bridges, pre-handled buyer objections, scarce calendar/portal routing, and the **Single Pulse CTA**.

---

## Execution Workflow

### Step 1: Calibration & RBM Verification
Check the workspace root for `LFM_PROFILE.md` and `LFM_PIPELINE.md` (and read `RBM_PROFILE.md` and `RBM_LEDGER.md` if present).
* **If `LFM_PROFILE.md` is missing**: Run **`lfm-calibrate`** first (auto-importing any verified settings from `RBM_PROFILE.md`).
* **Check RBM Offer Gate**: Verify the offer being promoted is not marked `CHRYSALIS PARK` or `NO` in `RBM_LEDGER.md`.

### Step 2: Rainmaker + Closer Tandem Execution
Spawn `lfm-lightning` and `lfm-firefly` (or coordinate via `lfm-synthesizer`):
1. **⚡ Lightning (`lfm-lightning`)** audits the topic, offer, carousel, reel, ad angle, or teardown across the **7 Voltage Bolts** (`/70`) and generates **3 High-Voltage Rainmaker Hooks** (Forensic Receipt, Margin-Bleed, Contrarian Operator).
2. **✨ Firefly (`lfm-firefly`)** takes Lightning's winning hook and engineers the **Velvet-Rope Conversion Sequence**:
   * Pre-handles the top 3 unspoken buyer objections (*Price/ROI, Proof/Trust, Effort/Timing*).
   * Scripts the Turn 1 -> Turn 2 -> Turn 3 Comment-to-DM or landing-page close (respecting the founder's `PEAK_4` / `LIGHT_1` / `BLACKOUT_0` calendar governor).
   * Locks in the **Single Pulse CTA**.

### Step 3: Deliver the Unified Conversion Brief & Sync `LFM_PIPELINE.md`
Present the combined **Lightning + Firefly** response clearly and update `LFM_PIPELINE.md` so **Rainbow** and **Butterfly** have live visibility into active campaigns and open hot threads.
